# Approach Risk 1.2 – Altitude Forecasting Pipeline

Исследовательский конвейер прогноза высоты на заходе: PostgreSQL, SQL, Ridge, Polynomial Ridge, PyTorch и MLflow. Сквозное исследование LFPG, EGLL и EDDF завершено 14.10.2026

Обучаемая поправка уменьшает среднюю ошибку относительно физического baseline во всех трех выборках. Универсального преимущества MLP над Polynomial Ridge не установлено: в LFPG лучше Polynomial Ridge, в EGLL преимущество MLP сохраняется на всех трех днях и пяти seed, в EDDF общий выигрыш MLP устойчив среди seed, но разница по отдельным дням меняет знак

**[Итоговый RESULT](RESULT.md)** содержит постановку, результаты, анализ неопределенности, чувствительность к seed, ограничения и следующий научный этап

## Основные результаты

MAE сначала усредняется внутри захода, затем между заходами. Все модели внутри аэропорта оценены на одинаковом test. Таблица относится к исходному seed 20261014

| Модель | LFPG MAE, ft | EGLL MAE, ft | EDDF MAE, ft |
| --- | ---: | ---: | ---: |
| Constant vertical rate | 49.35 | 55.95 | 72.60 |
| Ridge | 20.03 | 16.34 | 22.23 |
| Polynomial Ridge | **17.16** | 15.45 | 20.87 |
| PyTorch MLP | 18.86 | **14.52** | **20.56** |

Источник: [таблица метрик](reports/three_airports_metrics.csv). Test содержит 55 заходов LFPG, 1 136 EGLL и 540 EDDF. Дополнительная серия включает пять seed для каждой выбранной архитектуры, без выбора лучшего по test

## Что исследуется

Цель – последующая наблюдаемая высота через фактические 27–33 секунды. Baseline продолжает текущую вертикальную скорость, обучаемые модели прогнозируют поправку. Сезонные примеры и разбиение дней перенесены из завершенного Approach Risk 1.1: по 9 train, 3 validation и 3 test для каждого аэропорта

Заходы имеют равный вклад, преобразования обучаются только на train, параметры и лучший epoch выбираются по validation. Модели обучены отдельно для аэропортов. PostgreSQL сохраняет split, проверяет целостность и обеспечивает идемпотентную загрузку. MLflow содержит 12 исходных и 15 дополнительных MLP runs

Фактический горизонт входит в признаки и известен ретроспективно. Высота является барометрическим прокси. Результат не подтверждает онлайн-прогноз строго на 30 секунд, перенос на новые дни, go-around или эксплуатационную безопасность

## Воспроизведение на имеющихся локальных данных

Проверенное окружение: Windows, Python 3.12.14, PostgreSQL 17.11 на 127.0.0.1:55432. Завершенный проект `Approach Risk ver. 1.1` должен находиться рядом с текущим. Для полного ревью нужны локальные данные, модели, хранилище MLflow и работающий PostgreSQL. `DATABASE_URL` хранится в игнорируемом `.env`

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
powershell -File scripts/postgres.ps1 start
.\.venv\Scripts\python.exe scripts/verify_reproduction.py
```

Последняя команда не обучает модели. Она сверяет lock-файл и хеши источников, восстанавливает исходные и дополнительные модели, проверяет MLflow повторных запусков, выполняет тесты, диагностику и оба ноутбука

В отдельном окружении из lock-файла проверены 131 версия пакета и 45 исходных Parquet. Прошел 21 тест; восстановлены девять исходных моделей и 15 дополнительных MLP. [Машиночитаемый результат](reports/reproducibility.json)

Получение архивов с нуля и перенос всего исследования на новый компьютер не проверены. Импортированные классические модели LFPG происходят из 1.1; подробное объяснение находится в [финальном ревью](docs/FINAL_REVIEW.md)

## Запуск загрузки и обучения

Для каждого аэропорта загрузка и обучение запускаются отдельно. Команды ниже показывают LFPG; для EGLL и EDDF заменить значение `--airport`. Повтор одинакового импорта не добавляет строк. Повтор обучения создает новые MLflow runs и сохраняет модели текущего аэропорта; для просмотра готовых результатов он не требуется

```powershell
.\.venv\Scripts\python.exe scripts/audit_source.py --airport LFPG
.\.venv\Scripts\python.exe scripts/database.py --airport LFPG
.\.venv\Scripts\python.exe scripts/train.py --airport LFPG
.\.venv\Scripts\mlflow.exe ui --backend-store-uri sqlite:///mlflow.db --host 127.0.0.1 --port 5000
```

Проверки весов, bootstrap и управления seed без локальных данных и PostgreSQL:

```powershell
.\.venv\Scripts\python.exe -m pytest -q tests/test_preprocessing.py tests/test_uncertainty.py tests/test_seed_stability.py
```

Исходные данные, модели, окружения и все чекпоинты исключены из Git. Проект публикует код, выполненные ноутбуки и агрегированные отчеты. Следующий научный этап – прогноз на заранее заданные 30 секунд с признаками, доступными на момент прогноза, и новыми днями оценки
