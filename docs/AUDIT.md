# Проверка исходной выборки LFPG

Источник – завершенное сезонное исследование LFPG 09L в Approach Risk 1.1. Файлы examples.parquet содержат пары наблюдений; selected_days.csv задает фиксированное разбиение дней. Контрольные суммы записаны в reports/source_audit.json

| Характеристика | Подтвержденное значение |
| --- | ---: |
| Дней | 15 |
| Заходов | 553 |
| Пар наблюдений | 15 931 |
| Признаков | 9 |
| Дней train / validation / test | 9 / 3 / 3 |
| Заходов test | 55 |
| Пропусков и повторов ключа наблюдения | 0 |

Цель – последующая наблюдаемая высота через 27–33 секунды. Модели обучают поправку residual_ft к физическому baseline_ft. Каждый заход имеет одинаковый суммарный вес. StandardScaler обучается с теми же весами. Параметры выбираются по средней MAE заходов на validation

Проверены единственность дня и split для event_id, доступность METAR на момент origin_time, target_time до boundary_time, диапазон горизонта и соответствие временным меткам, согласованность baseline и residual

После загрузки в PostgreSQL и извлечения через JOIN все значения совпали с исходной выборкой. Повторная загрузка не добавила строк. При ошибках сверки изменения базы откатываются

Ограничения: одна полоса, отобранные погожие дни, повторение бортов между split, фактический горизонт как ретроспективно известный признак. Исторические NOTAM и эксплуатационная применимость не подтверждены. Условия распространения исходных примеров требуют проверки перед публикацией данных
