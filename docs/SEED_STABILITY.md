# Чувствительность MLP к seed

Дополнительный эксперимент оценивает вариативность обучения на тех же фиксированных днях. Исходные test-результаты уже известны, поэтому этап является описательной проверкой устойчивости, а не независимым подтверждением качества

До новых оценок зафиксированы seed 20261014, 20261015, 20261016, 20261017, 20261018. Для каждого аэропорта используется архитектура, выбранная в исходном эксперименте только по validation: LFPG 9 → 16 → 16 → 1; EGLL и EDDF 9 → 32 → 32 → 1. Новый поиск ширины или признаков не проводится

Сохраняются train/validation/test, веса заходов, обучение scaler только на train и масштаб residual. Adam использует learning rate 0.001 и weight decay 0.0001. Batch size 256, максимум 300 epochs, patience 30. Состояние с минимальной validation MAE выбирается отдельно в каждом запуске. Seed управляет инициализацией весов и перемешиванием minibatch. Используются два CPU-потока

Все 15 обучений выполняются перед новой оценкой test. Все результаты входят в отчеты. Лучший seed по test не выбирается; исходные модели и итоговые таблицы основного эксперимента сохраняются. Обученные модели, истории и локальная фиксация постановки не входят в Git. MLflow хранит отдельные runs, версии пакетов, хеши данных, моделей и исходников обучения. Хеш исходников описывает исполняемый код с локальными изменениями относительно записанного Git commit

Отчеты: `reports/seed_stability_runs.csv`, `seed_stability_metrics.csv`, `seed_stability_by_day.csv`, `seed_stability_summary.csv`. Среднее, выборочное стандартное отклонение, минимум и максимум описывают пять запусков; это не доверительные интервалы. Количество seed с отрицательной разницей MAE относительно Polynomial Ridge характеризует только эти выбранные seed и данные

Проверка `scripts/verify_seed_stability.py` восстанавливает прогнозы всех 15 моделей, сверяет общие и дневные метрики, validation MAE и сведения MLflow. Исходный seed дополнительно должен воспроизводить исходную MAE каждого аэропорта. Повтор полного обучения на другом компьютере и независимые дни здесь не проверяются

```powershell
.\.venv\Scripts\python.exe scripts/seed_stability.py --freeze
.\.venv\Scripts\python.exe scripts/seed_stability.py
.\.venv\Scripts\python.exe scripts/verify_seed_stability.py
```

Повторный запуск обучения при существующих артефактах завершится ошибкой, чтобы не заменить уже сохраненные модели. Для просмотра готовых результатов используется проверка без обучения
